# Audio asset

`ticking-clock.mp3` is the high-quality MP3 preview of **“Loopable Ticking Clock”** by OwlStorm (Ashe Kirk / Owlish Media). The larger “Tension Theme” audio file by Umplix is loaded directly from OpenGameArt at runtime rather than bundled in this repository.

- Ticking source: https://freesound.org/people/OwlStorm/sounds/212181/ (CC0 1.0 Universal, as stated on the source page).
- Music page: https://opengameart.org/content/tension-theme (CC0, as stated on the source page).
- Music file: https://opengameart.org/sites/default/files/tension_theme.wav
- CC0 deed: https://creativecommons.org/publicdomain/zero/1.0/

Both creators indicate attribution is optional. This note is kept for provenance. The tracks play together as looping clue ambience.
